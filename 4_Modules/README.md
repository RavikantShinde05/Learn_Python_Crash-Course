# This directory is about introduction to modules used in python

## List of Important Python Modules and Libraries:
1. Built-in Python Modules
These are included with Python, so you generally don't need to install them separately.
1. os – Operating system operations
2. sys – System-specific functions
3. math – Mathematical operations
4. random – Random number generation
5. datetime – Date and time handling
6. time – Time-related operations
7. json – JSON data handling
8. re – Regular expressions
9. collections – Specialized data structures
10. itertools – Iterator tools
11. functools – Functional programming utilities
12. pathlib – File and path management
13. shutil – File and directory operations
14. subprocess – Running external commands
15. logging – Application logging
16. argparse – Command-line argument parsing
17. sqlite3 – SQLite database operations
18. threading – Multithreading
19. multiprocessing – Process-based parallelism
20. asyncio – Asynchronous programming
21. unittest – Unit testing
22. statistics – Statistical calculations
23. csv – CSV file handling
24. hashlib – Hashing algorithms
25. secrets – Secure random values
26. socket – Network communication
27. pickle – Python object serialization
28. decimal – Precise decimal arithmetic
29. getpass – Secure password input
30. urllib – URL handling and HTTP requests
2. Popular Third-Party Python Libraries
These generally need to be installed using pip.
1. requests – HTTP requests
2. NumPy – Numerical computing
3. Pandas – Data analysis
4. Matplotlib – Data visualization
5. Seaborn – Statistical visualization
6. Scikit-learn – Machine learning
7. TensorFlow – Deep learning
8. PyTorch – Deep learning
9. OpenCV – Computer vision
10. Pillow – Image processing
11. BeautifulSoup4 – HTML parsing
12. Scrapy – Web scraping
13. Flask – Web development
14. Django – Web application development
15. FastAPI – API development
16. SQLAlchemy – Database toolkit and ORM
17. Pytest – Testing
18. Pydantic – Data validation
19. Streamlit – Interactive data applications
20. Gradio – Machine learning interfaces
21. Tkinter – GUI development (usually included with standard Python installations, though it may need a separate OS package)
22. PyQt – Desktop GUI development
23. Selenium – Browser automation
24. Playwright – Browser automation and testing
25. Celery – Background task processing
26. Pygame – Game development
27. NLTK – Natural language processing
28. spaCy – Natural language processing
29. Transformers – Pretrained AI models
30. Web3.py – Blockchain interaction

Domain	Useful modules and libraries
